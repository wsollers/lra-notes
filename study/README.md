# Study Capture

This directory holds learning artifacts that are useful before they belong in
Lean source or polished LaTeX notes.

- `remnote-queue.md` is the running list of cards to add to RemNote.
- `proof-sketches.md` stores short tactical proof sketches, especially the
  one-line "do this to show that" prompts.
- `lean-header-clauses.md` experiments with ways to visually parse Lean theorem
  statements before committing to source.

The files are deliberately lightweight. Add rough observations here during a
proof session; refine them later into RemNote cards, Google Doc sections, or
Lean comments only when they earn that permanence.
